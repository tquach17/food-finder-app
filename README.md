# 🍜 Food Finder App

Trending food spots powered by social media. Cross-platform mobile app (iOS & Android).

## Stack
- React Native + Expo + Mapbox
- Fastify API 
- PstgreSQL + PostGIS + Redis
- Supabase Auth

## Start
```bash
# mobile
cd apps/mobile && npm i && npx expo start
# api
cd apps/api && npm i && cp .env.example .env && npm run dev
```
